# Report format

Your response will be saved as a standalone Markdown report. A metadata
table (role, agent, query, harness, provider, model, timestamp, duration)
is prepended to it
automatically, so:

- Do not add a document title or any top-level (`#`) heading.
- Begin directly with your first `##` section heading.
- Use Markdown throughout: headings, lists, and fenced code blocks with
  language tags.
- Keep file paths and line references concrete and exact.
